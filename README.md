Breast Thermography Classification using Deep Learning
Project Overview

This project focuses on developing a machine learning/deep learning-based system for the classification of breast thermography images into two categories:
Benign
Malignant

The objective is to use thermal imaging data and deep learning techniques to assist in the classification of breast abnormalities. The project follows a structured pipeline starting from dataset preparation and patient-level splitting, followed by image preprocessing, model training, cross-validation, and performance evaluation.

Dataset
The project uses a Breast Thermography dataset containing thermal images organized according to patient IDs.
